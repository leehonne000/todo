## 2026-10-23（第一天）：产品定调 → 工程落地 → 数据库就位

### 一、产品设计修订与定调（决策记录）

1. **产品哲学定调**：系统管理"用户学过并手动记录的知识"，不推荐、不指派内容；**无任务实体**——"今日任务卡"措辞修正为"今日学习卡"（状态 = 当天有无学习 session）。此哲学写入产品文档并贯穿数据设计。
2. **科目编辑增加「类型」二选一**：note / 错题（必选，默认 note），随条目落库，用于分类筛选与统计（§4.3）。
3. **Review 流程简化**：取消「模糊 / 已掌握」自判环节，完成沉浸式复习直接回主界面；复习完成自动推进一轮，六轮走完出队，无重启机制（§6）。
4. **引入 MinIO 对象存储**：图片等二进制进 MinIO 私有桶（预签名 GET 读取），文字仍存 MySQL；部署升级四容器 compose（§10）。
5. **登录体系定稿**：邮箱 + 密码为主（注册邮箱验证码激活、找回密码走邮箱），手机号预留、v1 不做短信（§1.2）。
6. **主界面新增标签查询入口**：右上角查询**图标**（非搜索框），按标签查历史记录，结果按 note / 错题分两类展示（§3.1）。
7. **图片上限 6 → 10 张/条**，文字内容**可空**（允许纯图片记录，手机端拍照优先）；总结页子条目显示类型小徽标；**条数无上限**（一条子条目 = 一条记录）。
8. **提交规则修订**：产出一律不自动 commit/push，先交用户检查，用户确认后才做 git 操作。

### 五、后端地基 + 注册登录 API（2026-10-24 下午）

**工程结构**（`server/src/main/java/com/leehonne/examtimeline/`）：

- `entity/`：10 表 JPA 实体（`EntryTag` 复合主键、`Entry` 内嵌复习状态机、枚举转换器 type/review_status/purpose）。
- `repository/`：10 个 Repository（Spring Data JPA，方法名即查询）。
- `common/`：`ApiResponse` 统一响应、`BizException` 业务异常（错误码 1xxx 参数 / 2xxx 认证 / 3xxx 业务）、`GlobalExceptionHandler` 全局异常处理。
- `auth/`：`AuthService`（业务）/ `MailService`（QQ SMTP 发信）/ `JwtService` + `JwtAuthFilter`（JWT 签发与验票）/ `AuthController`（4 接口）/ `dto/`。
- `config/SecurityConfig`：`/api/auth/**` 放行，其余需 JWT；无状态会话。

**接口**（POST `/api/auth/`）：`send-code`（purpose 1=注册激活 2=找回密码）/ `register`（验码建号+录科目+发 token）/ `login` / `reset-password`。业务规则：60s 限频、10 分钟过期、验证码一次性消费、purpose 防串用、BCrypt 加密、激活后才可登录。

**登录验证**（11 用例全过，`temp/verify_auth_noemail.sh`，验证码直灌库不发信）：连通性×2、注册、重复注册拒、登录正/误密码、找回密码全流程、验证码复用拒、JWT 鉴权（带票 404 过门卫 / 不带 403）、落库核对。测试数据已清空。

**SMTP**：QQ 邮箱 3537572282@qq.com + 授权码入 `.env`（gitignore）；`.env.example` 占位模板。真实发信链路未端到端验证（测试用直灌替代），首次真实注册时验证。

**踩坑记录（三个，均已修复）**：

1. **JDBC 字符集**：`characterEncoding=utf8mb4` 驱动不认（`Unsupported character encoding`）→ 改 `UTF-8`（Java 字符集名），库表本身仍是 utf8mb4。
2. **SERVER__PORT 环境变量劫持**：WorkBuddy 会话环境带 `SERVER__PORT=62647`，Spring 松散绑定将其识别为 `server.port` 覆盖配置 → 服务去抢 WorkBuddy 端口启动失败。**启动必须带 `--server.port=8080`**（命令行参数优先级最高）。
3. **MySQL 容器 UTC 时区**：容器时钟比北京时间慢 8 小时，直灌 SQL 的 `NOW()` 与 Java `LocalDateTime` 对不上（验证码"提前过期"）。已用 `TZ=Asia/Shanghai` 重建容器（数据卷 `exam-mysql-data` 保留）。JPA 写入路径不受影响（JVM 时区正确），但定时/默认值口径现与产品文档一致。
