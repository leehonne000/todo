## 1. 产品定位

**面向多用户的「考研时间线规划辅助系统」**——不是普通 todo 工具。

设计哲学借鉴《不背单词》App：**系统替用户安排学习，而不是让用户记录待办**。
用户只负责"学"和"记"，系统负责"什么时候该复习什么"。

### 1.1 设计哲学（不背单词借鉴点）

| 不背单词的做法 | 本产品的对应 |
|---|---|
| 打开 App 就是今日学习任务 | 打开就是主界面：签到 + 今日学习 + 今日应复习 |
| 系统按记忆曲线安排单词复习 | 系统按艾宾浩斯曲线安排 note/错题复习 |
| Learn / Review 卡片直达 | Learn / Review 卡片直达，全屏沉浸式流程 |
| 壁纸 + 毛玻璃 + 琥珀橙数字 | 同款视觉语言（见 §7） |
| 底部三图标导航 | 底部三图标 = 三大模块入口（hub-and-spoke） |

### 1.2 目标用户与多用户

- **多用户系统**，账号注册制。
- **注册时确定两件事：考研届数 + 科目组合**（绝大多数为四门，如 政治 / 英语一 / 数学三 / 计算机学科专业基础综合(408)）。之后所有模块按此科目组合四选一。
- 不局限于任何一届考生——届数、科目均为用户自定义。

### 1.3 明确不做（v1）

- 商业化、组队、社交（不背学堂类功能）——留空位不实现。
- OCR（图片不识别文字，v1 只存图）。
- 离线支持（待定，见 §10）。

## 2. 导航模型：中心辐射（hub-and-spoke）

**这是被多次纠正后定稿的关键结构，实现时不得走样：**

- 进入应用后**默认显示主界面**（根屏），主界面**不与任何底部图标绑定**。
- 底部导航栏三个图标 = 三大模块**入口**（不是平行 tab）：
  - **左：信息模块** —— 「距离 XXXX 年考研还有 XXX 天」等信息、考研硬节点时间线。
  - **中：复习模块** —— 对过去学过内容的**自由库**复习。
  - **右：进度模块** —— 对整体的规划与统计。
- **无论从哪个模块退出，都直接退回主界面**（不回上一个模块、不在模块间切换）。
- 主界面自己提供 Learn / Review 两个卡片入口（见 §3）。

```
              ┌─────────────┐
   信息模块 ←──┤   主 界 面   ├──→ 复习模块
              │ (常驻根屏)  │
   进度模块 ←──┤             │
              └─────────────┘
   （退出任一模块 → 直接回主界面）
```

## 3. 主界面

主界面包含三块内容：

1. **签到**（每日打卡）。
2. **今日学习卡（Learn）** —— 今天的**学习入口 + 学习状态**（今天完成过 Learn session 则打勾）。注意：系统**没有"任务"实体**——内容全部由用户学完手动记录，系统不布置任务；点击进入 Learn 沉浸式流程（§4）。
3. **今日应复习卡（Review）** —— **艾宾浩斯复习队列的唯一入口**。到期待复习的 note/错题在此汇总，点击进入全屏沉浸式复习流程（§6）。

> 关键澄清：艾宾浩斯队列**只**通过主界面 Review 卡消费；底部中间的复习模块**不提供**队列，只是自由库（见 §5.2）。

## 4. Learn 流程（今日学习卡点入）

### 4.1 计时界面（横屏沉浸式）

- **手机端锁死横屏**。
  - 注意：iOS Safari 网页不支持硬锁横屏，方案为**"请横过来"整屏引导遮罩**替代硬锁；Android/PC 按需处理。
- 横屏界面四要素（用户手绘草图定稿）：
  1. **最中间**：当前时间（时分秒，或用户自定义为时分）。
  2. 当前时间**上方**：小字号的**学习计时器**。
  3. **左下角**：**暂停按钮**（圆形蓝色）；点击暂停计时，按钮变为**正方形**（暂停态）。
  4. **右下角**：**结束按钮**，**长按**才结束本次学习的计时部分。

### 4.2 学习总结页（长按结束后进入）

界面极简，只有两个元素（多余元素全部删除）：

- **「＋添加科目」** 通栏毛玻璃框。
- **右下角琥珀色「Done」** 胶囊按钮。

交互：

- 点「＋添加科目」→ 进入**科目编辑界面**（§4.3）。
- 编辑完成后返回总结页，该科目以**子条目**形式**紧紧贴在「添加科目」框正下方**——比「添加科目」框**小一点**、像它的**子标签**（`margin-top: 3px`、左缩进、圆角只在下方、字号更小、右侧 `›` chevron），点击子条目可再次进入编辑。子条目携带所选的**科目 + 类型（note / 错题）**。
- 可添加多门科目（本次学习涉及几门加几门）。
- 点「Done」→ 本次学习 session 数据落库（见 §8 数据引擎闭环）。

Demo 参考：`temp/learn_summary_1_empty.html`（空态）、`temp/learn_summary_2_subject_added.html`（已加"计算机学科专业基础综合(408)"子条目）。

### 4.3 科目编辑界面

Demo 参考：`temp/subject_edit_demo.html`（可交互）。

- **折叠式「科目」选项卡**（关键设计，因平铺四个选项太占屏幕上方空间）：
  - 默认折叠，只显示一行「科目 ▾」。
  - 点击展开四个科目选项（来自注册时确定的科目组合，四选一单选）。
  - 选中后选项卡**自动折叠**，框内显示所选科目名。
  - 未选科目点「完成」→ 自动展开选项卡并提示。
- **「类型」二选一选项卡：note / 错题**（2026-10-23 新增）：与科目选择并列的二选一，必选其一（默认 note）。类型随该条目落库，用于分类、筛选与统计；note 与错题都自动进艾宾浩斯队列（§6）。
- **文字内容**输入区。
- **图片插入**：「＋」虚线方块触发。
  - 手机端：读取手机相册或拍照；电脑端：上传图片。
  - 缩略图（72px）可删除，**上限 6 张**。
  - 服务端压缩后存入 **MinIO 对象存储**（私有桶，见 §10）；v1 不做 OCR。
- **自定义标签**：点「＋标签」变为输入框，回车生成琥珀色 chip；点 chip 上 `x` 删除。
- 完成后回到学习总结页（§4.2）。

## 5. 三大模块

### 5.1 信息模块（底部左）

- 「距离 XXXX 年考研还有 XXX 天」等信息展示。
- **考研硬节点时间线**（数据化，不写死；每年教育部公布后更新数据）：
  | 节点 | 大致时间 |
  |---|---|
  | 预报名 | 9 月底 |
  | 正式报名 | 10 月中 |
  | 网上确认 | 11 月初 |
  | 准考证下载 | 12 月初 |
  | 初试 | 12 月 |
  | 出分 | 次年 2 月 |
  | 国家线 | 3 月中 |
  | 复试 / 调剂 | 3–4 月 |

### 5.2 复习模块（底部中）—— 自由库

- 对**所有** note 和错题的**自由浏览与复习**，**按科目分类**。
- **不提供艾宾浩斯复习队列**（队列只在主界面 Review 卡，§3/§6）。
- 用户可主动翻阅、筛选、修改已记录的 note/错题内容。

### 5.3 进度模块（底部右）

- **以日期为轴**的个人进度管理。
- 每日统计：**各科目学习耗时**、各科目笔记数、各科目错题数之类。
- 数据来源：Learn session 的计时与记录（§8）。

## 6. 艾宾浩斯复习机制（★ 定稿）

### 6.1 复习间隔

**标准节奏：1 / 2 / 4 / 7 / 15 / 22 天，共六轮。**（2026-10-23 用户拍板）

- 用户在学习总结中输入的**所有 note / 错题**，自动全部进入艾宾浩斯复习队列。
- 今天记录的内容，分别在 **1 天后、2 天后、4 天后、7 天后、15 天后、22 天后** 应复习。
- 到期项出现在主界面「今日应复习」Review 卡（**队列唯一入口**）。
- 点 Review 卡进入**全屏沉浸式复习流程**（复盘用户自己记录的错题和结论，按科目组织）。
- **复习过程无自判环节**（2026-10-23 修订：取消原「模糊 / 已掌握」两键判定）。完成全部到期项的沉浸式复习后**直接回到主界面**。
- **每完成一次复习自动推进一轮**（round + 1，下一轮到期日照节奏顺延）；**六轮全部完成后出队**（仅留复习模块自由库可查）。
- **v1 节奏写死，不开放用户自定义间隔**。
- Review 卡显示当日到期数（跨科目堆叠计数）。

> 说明：此前讨论中出现过的 1/2/4/9/18 天为随手举例的错误数字，已废弃；以本节数字为唯一准绳。

### 6.2 与复习模块的边界

| | 主界面 Review 卡 | 底部中间复习模块 |
|---|---|---|
| 艾宾浩斯队列 | ✅ 唯一入口 | ❌ 无队列 |
| 内容 | 今日到期项 | 全部 note/错题自由库 |
| 形式 | 全屏沉浸式复习 | 按科目自由浏览 |

## 8. 数据引擎闭环（核心数据流）

**一次学习 session 产出三份数据，喂饱三个模块：**

```
Learn session（计时 + 总结）
   ├─ 学习时长 ────────→ 进度模块（每日各科耗时统计）
   ├─ note / 错题 ─────→ 复习模块自由库 ＋ 艾宾浩斯队列（Review 卡消费）
   └─ 学习完成情况 ────→ 主界面今日学习卡（打勾状态）
```

- note/错题入库时即按 §6.1 生成六个复习到期点（记录日起第 1/2/4/7/15/22 天）。
- 每完成一次复习自动推进一轮；六轮走完出队（**无自判、无重启机制**，2026-10-23 修订）。

## 10. 技术栈与部署（已拍板）

**Spring Boot 3.x + Vue3 + MySQL + MinIO + Docker**，四容器 compose（MinIO 为 2026-10-23 增补）：

| 容器 | 职责 |
|---|---|
| Nginx | 托管 Vue 静态页 + 反代 `/api` + TLS 终结 |
| Spring Boot | REST API + 登录鉴权 + 图片压缩中转 |
| MySQL | 结构化数据持久化（文字内容、统计、复习状态），数据卷 `./data/mysql` |
| MinIO | **二进制对象存储**（图片等），私有桶 `exam-timeline`，数据卷 `./data/minio` |

### 图片存取链路（MinIO）

- **上传**：前端 → Spring Boot（multipart）→ 服务端压缩（缩放/转 webp 或 jpeg）→ 写 MinIO（object key 形如 `user_{id}/entry_{id}/{uuid}.webp`）→ MySQL 只存元数据（`t_entry_image`：object_key、content_type、size 等）。
- **读取**：私有桶 + 后端签发**预签名 URL**（presigned GET，短时效），前端拿 URL 直接渲染；不走后端流量中转。
- **文字内容一律存 MySQL**（可检索、可统计），MinIO 只管二进制。
- 需要图片直传优化时再升级为预签名 PUT 直传，v1 不做。

- **VPS**：建议 **≥ 2G 内存**（MySQL ~400MB + JVM ~300–500MB + MinIO ~100MB）。
- **备份**：`mysqldump` 每日 cron 定时备份 + MinIO 数据卷同步（`mc mirror` 或磁盘快照）。
- **HTTPS（裸 IP 访问，如 `https://122.22.222.1`）**：
  - 首选：**Let's Encrypt IP 证书**（2026-01-15 GA）——但**仅 6 天短期证书**（shortlived，160 小时），必须 **Certbot ≥ 5.4 全自动续期**（http-01 / tls-alpn-01），续期不能断。
  - 备选：免费域名 + 90 天常规证书。
- **备案**：国内 VPS 纯 IP 通常可行但不保证；中国香港 VPS 无备案限制。
- 图片：手机相册/拍照、电脑上传，服务端压缩后入 MinIO。
