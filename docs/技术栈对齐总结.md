## 五、契约变更（三端同步）

| 项 | 旧 | 新 |
|---|---|---|
| 成功码 | `code=0` | **`code=200`**（`ResultCode.SUCCESS`） |
| 错误码 | 1001/1002/2001/2002/3001/3002/3003/5000 | 不变（收进 `ResultCode` 枚举） |
| 分页 | `{items,total,page,size}` | **PageVO** `{records,current,size,total,pages}` |
| 硬节点列表 | `{items:[...]}` | 纯数组 `[...]` |
| HTTP 状态 | 校验失败 400 等 | **业务失败一律 200 + code**；仅未登录拦截器回 401 |
| 响应类命名 | `*Request/*Response` | `*DTO/*VO`（JSON 字段不变） |

影响面已同步：`docs/接口文档.md`、`docs/联调手册-登录与Learn.md`、两个前端（client/request/mock/8 处视图）、`temp/verify_*.sh`。
