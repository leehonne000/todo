Name · 名字释义

考研是一场漫长而高压的修行。与其在焦虑里诅咒，不如像一棵大树那样——把根深深扎进土里，沉默地积蓄力量。 飘来的是云，飘去的也是云；今天没人识得星星一颗，明天何妨做皓月一轮。名字取自汪国真《倘若才华得不到承认》中的「大树的精神」。

🌳

Big Tree · 大树

一棵概括的卡通树：不喧哗、不急躁，把力气用在看不见的地方。呼应产品哲学：只沉淀真正学过的东西。

🌱

扎根 · 时间规划

脚下一枚小土丘，就是"扎根"的全部表达——不张扬，但稳。每一天的学习记录、复习节奏，都是向下扎的一步。

✨

星星 → 皓月

「既然今天没人识得星星一颗，那么明日何妨做皓月一轮」。左侧的星芒是尚未被看见的努力，也是明日的自己。

🎨

不对称构图

树干偏右约 3/4 处，树冠向左舒展，星星落在左侧留白——不是端端正正的"图标脸"，更像绘本里的一棵树。

与其诅咒 不如坚忍 在坚忍中积蓄力量 默默耕耘 …… 飘来的是云 飘去的也是云 既然今天 没人识得星星一颗 那么明日 何妨做 皓月一轮—— 汪国真《倘若才华得不到承认》（节选）

Usage · 使用建议

App 启动页

深绿渐变底 + 白色图形标居中，底部一行小字「在坚忍中积蓄力量」，3 秒后进入主界面。

PWA / 桌面图标

使用 big-tree-icon.svg 导出 512/192/180/128/64/32 全套尺寸，圆角系统按各自平台规范裁切。

PC 用户端侧边栏

横排组合标（big-tree-logo.svg）置于侧边栏顶部，毛玻璃面板上用墨绿字版本即可。

管理后台

用图形标单色版（绿或墨绿单色）即可，弱化存在感，保持后台工具气质。
